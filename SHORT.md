# Лекция 1

## Основы работы с Git
* `git config` — инициализировать имя и почту.
* `git init` — инициализировать репо в папке.
* `git clone` — склонировать удаленный репозиторий в папку.
* Рабочий процесс: рабочая директория -> `[git add]` -> подготовленные изменения (stage) -> `[git commit]` -> изменения, вписанные в историю.
* `git status` — состояние репо.
* `git reset HEAD filename` — убрать файл из stage.
* `git checkout -- filename` — подтянуть файл из последнего коммита (изменения не откатываются, можно потерять незакоммиченные правки).
* `git commit` — добавить stage в commit.
* `git rm --cached filename` — убрать файл из отслеживания ("удалить в глазах гита", но физически оставить локально).
* `.gitignore` — файл со списком того, что гит не должен отслеживать.
* `git log` — история коммитов.

## Ветвление и слияние (Merge)
* `git branch` — показать текущую ветку.
* `git branch -D name` — удалить ветку с названием `name`.
* `git branch --all` — показать все ветки.
* `git checkout name` (с флагом `-b`, если ветку надо создать) — переключиться на ветку.
* `git checkout [commit id]` — перейти к устаревшему коммиту. В этом случае мы переходим в состояние `detached HEAD`. Оно опасно: если решить в этом состоянии что-то изменить и сохранить (сделать коммит из `detached HEAD`), его не будет видно при `git log` из `main`-ветки (головы). Так коммит можно потерять, поэтому так делать не надо.
* `git merge branch_name` — влить изменения из `branch_name` в текущую ветку.
* Слияние (merge) бывает трёх видов:
    * **fast-forward** — когда в основной ветке, в которую мы мерджим, не было изменений, и мы просто "ставим этажик сверху".
    * **Обычное слияние** — обе ветки развивались параллельно, но меняли разные файлы или разные строчки. Git автоматически объединяет их и создает новый специальный коммит слияния (`merge commit`).
    * **Merge conflict** — один и тот же файл изменили в обеих ветках по-разному. В этом случае Git не знает, какая версия правильная, останавливает слияние и просит отредактировать файл руками.

## Работа с удаленным репозиторием
* `git fetch origin` — подтянуть изменения с удаленного репо. Команда обновляет так называемые "трекинговые ветки" (скрытые копии серверных веток на компьютере, например `remotes/origin/main`).
* `git pull = git fetch && git merge origin/<branch_name>`.
* `git push` — попытка сделать fast-forward слияние текущей локальной ветки с соответствующей веткой на сервере. Если нет синхронизации с удалённым репо, выдаст конфликт версий. В таком случае нужно сделать `git pull`, разрешить конфликт и сделать `push`.
* `git push --force` — затирает удалённый репо текущей локальной версией. Использовать осторожно, так как можно убить чужие изменения.

# Лекция 2

## Базовые типы данных и структуры
`obj[start:stop:step]` — синтаксис среза.
#### Словарь

Ну это словарь. Методы:

Добавление и изменение элементов
* **`update([other])`**
  Обновляет словарь парами ключ-значение из другого словаря или итерируемого объекта (например, списка кортежей). Если ключ уже существует, его значение перезапишется.
  *Пример:* `d.update({'a': 3, 'b': 2})`
* **`setdefault(key, default)`**
  Если ключ есть в словаре, возвращает его значение. Если ключа нет, добавляет его со значением `default` (по умолчанию `None`) и возвращает это значение.
  *Пример:* `d.setdefault('c', 100)` (если 'c' не было, оно появится со значением 100).

Удаление элементов
* **`pop(key, default)`**
  Удаляет указанный ключ и **возвращает** его значение. Если ключа нет и передан `default`, возвращает `default`. Если ключа нет и `default` не указан — выкинет ошибку `KeyError`.
  *Пример:* `val = d.pop('a', 0)`
* **`popitem()`**
  Удаляет и возвращает **последнюю добавленную** пару `(ключ, значение)` в виде кортежа (правило работает для Python 3.7+). Если словарь пуст — выкинет `KeyError`.
  *Пример:* `last_pair = d.popitem()`
* **`clear()`**
  Полностью очищает словарь, удаляя все ключи и значения.
  *Пример:* `d.clear()`
* `del birthdays['Bob']` - удаление ключа

Доступ к данным и просмотр. Методы ниже возвращают специальные динамические объекты-представления. Если словарь изменится, эти объекты тоже автоматически обновятся.
* **`get(key, default)`**
  Безопасное получение значения. Если ключ есть — возвращает значение. Если нет — возвращает `default` (по умолчанию `None`), не вызывая ошибку `KeyError`.
  *Пример:* `d.get('a', 0)`
* **`keys()`**
  Возвращает коллекцию всех ключей в словаре.
  *Пример:* `d.keys()`
* **`values()`**
  Возвращает коллекцию всех значений в словаре.
  *Пример:* `d.values()`
* **`items()`**
  Возвращает коллекцию всех пар в словаре в виде кортежей `(ключ, значение)`. Удобно для циклов `for`.
  *Пример:* `for k, v in d.items():`

Создание и копирование
* Напрямую:
```python
birthdays = {'Alice': 123, 'Bob': '1999-12-31'}
birthdays['Sam'] = '1972-01-01'
```
* **`fromkeys(iterable, value)`**
  Создает **новый** словарь, беря ключи из переданной коллекции `iterable` и присваивая им всем одинаковое значение `value` (по умолчанию `None`). 
  *Пример:* `dict.fromkeys(['a', 'b', 'c'], 0)` (создаст `{'a': 0, 'b': 0, 'c': 0}`).

#### Список

Это изменяемый набор родственных элементов. Методы:

Добавление элементов
* **`append(x)`**
  Добавляет один элемент `x` в самый конец списка. 
  *Пример:* `a.append(4)`
* **`extend(iterable)`**
  Берет другую коллекцию (список, кортеж, строку) и по одному добавляет все ее элементы в конец текущего списка.
  *Пример:* `a.extend([4, 5])` (в отличие от `append`, список не станет вложенным).
* **`insert(i, x)`**
  Вставляет элемент `x` на указанную позицию по индексу `i`. Все остальные элементы сдвигаются вправо.
  *Пример:* `a.insert(0, 100)` (вставит 100 в самое начало).

Удаление элементов
* **`remove(x)`**
  Ищет в списке первый элемент со значением `x` и удаляет его. Если такого элемента нет, Питон выдаст ошибку `ValueError`.
  *Пример:* `a.remove('apple')`
* **`pop([i])`**
  Удаляет элемент по индексу `i` и **возвращает** его значение (можно сохранить в переменную). Если вызвать просто `a.pop()` без аргументов, он удалит и вернет *самый последний* элемент списка.
  *Пример:* `last_item = a.pop()`
* **`clear()`**
  Полностью очищает список, удаляя из него абсолютно всё. Список становится пустым `[]`.
  *Пример:* `a.clear()`

Поиск и информация
* **`index(x, start, end])`**
  Ищет элемент `x` и возвращает его индекс (позицию). Можно дополнительно указать, с какого и по какой индекс искать. Если элемента нет — выдаст ошибку `ValueError`.
  *Пример:* `a.index('apple')`
* **`count(x)`**
  Подсчитывает и возвращает, сколько раз значение `x` встречается в списке.
  *Пример:* `a.count(5)`

Изменение порядка (работают in-place). Эти методы изменяют сам список в памяти, а не создают новый, и всегда возвращают `None`.
* **`sort(*, key=None, reverse=False)`**
  Сортирует элементы списка. Можно передать функцию в `key` (например, `key=len`, чтобы отсортировать строки по длине) или указать `reverse=True` для сортировки по убыванию.
  *Пример:* `a.sort(reverse=True)`
* **`reverse()`**
  Разворачивает список задом наперед.
  *Пример:* `a.reverse()` (работает так же, как срез `a[::-1]`, но не тратит память на создание нового списка).

#### Кортеж 
Это неизменяемый набор. Методы:

Методы изменения отсутствуют (иммутабельность)
* Попытка изменить элемент напрямую (например, `x[0] += [1]`) приведет к ошибке `TypeError: 'tuple' object does not support item assignment`.

Создание
* **Сложение (`+`)**
  Склеивает два кортежа. Создает абсолютно новый объект.
  *Пример:* `b = b + a`.
* **Прибавление с присваиванием (`+=`)**
  Делает то же самое — создает новый кортеж и перезаписывает ссылку в переменной.
  *Пример:* `b += a`.

Функции и системные методы
* **`len(obj)`**
  Встроенная функция для получения длины кортежа. Упоминается в чеклисте лекции ("Взять длину от тупла?").
  *Пример:* `len(a)`..


Упаковка и распаковка
* **Packing** — упаковка данных (по умолчанию происходит в кортеж).
* **Unpacking** — распределение (распаковка) элементов по переменным.
* Символ `*` используется для забора остатка данных в объект:
```python
numbers = (4, 8, 15, 16, 23, 42)
a, b, c, d, e, f = numbers

colors = ('red', 'green', 'blue')
red_variable, *other_colors = colors

a, *b, c = [1, 2, 3, 4]
```

## Операторы, условия и проверки
* Присутствует явное и неявное приведение типов.
* В условиях используются `if`, `else`, `and`, `or`.
* Операторы `or` и `and` вычисляются до детерминизации (лениво).
* Проверка на `None` должна выполняться через `is None`, а не `== None`, чтобы избежать непредвиденной конвертации типов.
* Моржовый оператор `:=` присваивает значение переменной и одновременно выдает это присвоенное значение.
* Конструкция `match` / `case` используется для сопоставления с шаблоном:
```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

point = Point(1, 42)

match point:
    case Point(x=0, y=0):
        print("Origin")
    case Point(x=0, y=y):
        print(f"Y={y}")
    case Point(x=x, y=0):
        print(f"X={x}")
    case Point():
        print("Somewhere else")
    case _:
        print("Not a point")
```
* Вывод кода выше:
```text
Somewhere else
```

## Циклы и встроенные функции
* Цикл `for` используется в связке с `range` или по контейнеру. Он применяется, когда мы работаем с элементами последовательно и независимо друг от друга, иначе лучше использовать `while`.
* Функция `reversed(obj)` используется вместо среза `obj[::-1]`.
* `enumerate(data)` отображает объекты `data` в кортежи формата `(индекс, объект)`.
* `zip(list1, list2)` собирает соответствующие элементы из списков в кортежи.
* Для управления циклом применяются `continue` и `break`.
* В цикле `for` можно использовать блок `else`, который срабатывает, только если `for` полностью отработал без `break`:
```python
for line in ['Hello', 'World', 'Library']:
    if len(line) > 7:
        print("Found long line!")
        break
else:
    print("All lines are short") 
```
* Функция `print(obj, end="sth")` позволяет заменить стандартный символ окончания строки.
* Встроенные математические функции: `sum`, `min`, `max`.

## Функции, типизация и документация
* Функции объявляются через ключевое слово `def`.
* Аннотация типов (типизация) выполняется с помощью модуля `typing`:
```python
import typing as tp

def f(
    int_value: int,
    float_value: float,
    any_value: tp.Any
) -> None:
    pass

f(
    int_value=10, 
    float_value=10.1, 
    str_value=str, 
    list_value=["a", "b"],
    tuple_value=("a", "b"),
    optional_str_value="hello",  # or None
    str_or_int_value="world",  # or 1
    type_value=int,
    any_value=12345  # or any other type
)
```
* Документация (docstring) к методу пишется в тройных кавычках внутри функции. Команда `help(ctr2)` выведет эту документацию в консоль:
```python
def ctr2(clicks: int, shows: int) -> float:
    '''
    Calculate ctr. If there are no shows, return 0.
    :param clicks: number of clicks on banner
    :param shows: number of banners shows
    :return: clicks-through rate
    '''
    if shows != 0:
        return clicks / shows
    return 0.0
```
* Конструкция `assert cond, comment` используется для самопроверки кода.

# Лекция 3

## Память, ссылки и мутабельность
* `id(obj)` возвращает ссылку на объект в памяти компьютера.
* Создание коллекций через умножение `*` (например, `[0]*3`) следует использовать только для неизменяемых объектов.
* **Иммутабельные (неизменяемые) объекты** не меняют значение по ссылке. Примеры: `int`, `float`, `str`, `tuple`, `frozenset`.
```python
a = 1
b = a
a += 2
a, b
```
* Вывод кода выше:
```text
(3, 1)
```
* **Мутабельные (изменяемые) объекты** меняют значение по ссылке. Примеры: `list`, `set`, `dict`.
```python
a = [1]
b = a
a += [2]
a, b
```
* Вывод кода выше:
```text
([1, 2], [1, 2])
```

## Внутреннее устройство базовых типов
### Тип `int`
* **Иммутабельность:** Тип `int` неизменяем. При любой математической операции (например, `a += 1`) старый объект в памяти не меняется — создается совершенно новый объект, и переменная начинает ссылаться на него.
* **Бесконечность:** У `int` в Питоне нет предела и переполнения. Число может быть любой длины, Питон просто будет выделять под него больше памяти по мере роста.
* **Кэширование (оптимизация):** Маленькие числа (до 256) заранее закэшированы в памяти. Если написать `a = 1` и `b = 1`, они будут ссылаться на один и тот же объект (`a is b` выдаст `True`). Для чисел от 257 и выше будут создаваться разные объекты с разными `id`.
* **Большой вес:** Из-за своей сложной структуры числа в Питоне довольно "тяжелые". Даже обычная единица (1) весит 28 байт.
* **Структура в памяти:** Любое целое число состоит из 4 блоков:
    1. Счетчик ссылок (8 байт).
    2. Ссылка на тип объекта (8 байт).
    3. Знак числа и его размер в системе счисления по основанию 2 в 30-й степени (8 байт).
    4. Сами данные — "кусочки" числа, каждый из которых весит по 4 байта.

### Тип `float`
* **Иммутабельность:** Как и целые числа, вещественные числа неизменяемы. Любая математическая операция создает новый объект в памяти с новым `id`.
* **Отсутствие кэширования:** Для `float` нет встроенного кэша. Если написать `a = 1.1` и `b = 1.1`, Питон создаст два независимых объекта с разными `id`.
* **Ограниченность и потеря точности:** `float` не бесконечен. У него есть максимальное значение (около $1.79 \times 10^{308}$). Из-за особенностей хранения возникает потеря точности: например, `float(10**16 - 1) == 10**16` выдаст `True`, потому что "младшие" разряды отбрасываются.
* **Специальные значения:** Поддерживает концепцию бесконечности `float('inf')` и "не числа" `float('nan')`. `nan` не равен даже самому себе (`nan == nan` выдает `False`).
* **Строго фиксированный вес:** Любой `float` (даже самое гигантское значение или бесконечность) всегда весит ровно 24 байта.
* **Структура в памяти (3 блока по 8 байт):** Счетчик ссылок, ссылка на тип объекта, само значение числа (хранится в формате языка C как `double`).

### Тип `str`
* **Иммутабельность:** Строки абсолютно неизменяемы. Попытка приклеить к строке кусок (например, `b += " world"`) создает в памяти новую строку с новым `id`.
* **Интернирование (Оптимизация):** Python автоматически кэширует (интернирует) некоторые строки (обычно короткие слова без спецсимволов). Например, `a = "helloworld"` и `b = "helloworld"` будут ссылаться на один и тот же объект.
* **Ручное интернирование:** Большие сгенерированные строки можно заставить ссылаться на одну память принудительно через `sys.intern()`:
```python
import sys
a = sys.intern("a" * 100500)
b = sys.intern("a" * 100500)
id(a) == id(b)
```
* **Базовый вес:** В лекции показано, что строка `"shad2024"` занимает 49 байт памяти.
* **Структура в памяти:** Счетчик ссылок (8 байт), ссылка на тип объекта (8 байт), длина строки (8 байт), хэш строки (8 байт), флаги и служебная информация (включая метку интернирования, 16 байт), сами байты символов (заканчиваются нулевым байтом `\00`, занимают от 1 байта).

## Внутреннее устройство контейнеров
### `list` (Списки)
* **Мутабельность:** Список изменяем. Операции `lst.append(elem)`, `lst1.extend(lst2)` или `b += [2]` меняют существующий объект в памяти. А вот `b = b + [2]` создаст новый список.
* **Самозацикливание:** В список можно положить ссылку на него самого (`a.append(a)`), что приведет к бесконечной вложенности вида `[[...]]`.
* **Аллокация (запас памяти):** Пустой список весит 40 байт. В памяти хранится не только текущая длина, но и зарезервированная (capacity), чтобы при каждом `.append()` не просить новую память.
* **Структура в памяти:** Счетчик ссылок, ссылка на тип, текущая длина, ссылка на массив с данными, зарезервированная длина (всё по 8 байт). Элементы лежат в отдельном массиве ссылок (по 8 байт на каждый элемент).

### `tuple` (Кортежи)
* **Иммутабельность (с подвохом):** Сам кортеж неизменяем. Но если внутрь положить изменяемый объект (например, `x = ([], 1, 2)`), то этот внутренний список можно менять через `x[0].append(1)`.
* **Коварный `+=`:** Операция `x[0] += [1]` честно изменит внутренний список, но при попытке переприсвоить его обратно в кортеж выкинет ошибку `TypeError: 'tuple' object does not support item assignment`.
* **Оптимизация:** Кортежи легче списков — пустой кортеж весит всего 24 байта. Пустой кортеж `()` закэширован как синглтон (ссылается на одну ячейку памяти).
* **Структура в памяти:** Нет запаса под аллокацию. Хранит счетчик ссылок, ссылку на тип, длину и массив ссылок на элементы.

### `set` и `frozenset` (Множества)
* **Только хэшируемые типы:** Множество работает как хэш-таблица. Внутрь можно класть только неизменяемые типы, иначе будет `TypeError: unhashable type`:
```python
a = set()
a.add((1, 2))
```
* **Огромный вес:** Абсолютно пустой `set()` весит 200 байт.
* **Структура в памяти:** Хранит счетчик ссылок, тип, длину, число заполненных и доступных ячеек, ссылку на таблицу, хэш, и вшитую маленькую хэш-таблицу (на 8 записей) для скорости.
* **`frozenset`:** Неизменяемый брат множества без методов изменения (`.add()`, `.pop()`). Операции объединения (`|`) создают новый объект. Весит те же 200 байт, но может использоваться как ключ словаря или лежать внутри другого множества:
```python
a = frozenset([1, 2, 3])
b = frozenset([3, 4, 5])
a - b, b - a
a | b, a & b
```

### `dict` (Словари)
* **Изменение размера в цикле:** Запрещено удалять или добавлять ключи, пока итерируетесь по словарю циклом `for k in d:`, это вызовет `RuntimeError: dictionary changed size during iteration`.
* **Ключи:** Могут быть только хэшируемым объектом. Конструкция `{[1, 2]: 3}` выкинет ошибку.
* **Оптимизация:** В версии Python 3.6+ словари используют плотный массив значений и отдельный массив индексов. Очищенный словарь весит 48 байт и запоминает порядок добавления ключей.

## Копирование
* Если объект имеет вложенную мутабельность, его необходимо копировать через `deepcopy`, иначе можно обойтись `copy`:
```python
from copy import copy
a = [1, 2, 3]
b = copy(a)
b[0] = 4

from copy import deepcopy
a = [1, 500, []]
b = deepcopy(a)
b[2].append(3)
```

## Генераторы (Comprehensions)
* В Python доступен компактный синтаксис для создания коллекций с условиями и без:
```python
lst = [i ** 2 for i in range(5)]
dct = {i : i**2 for i in range(5)}
st = {i for i in range(10)}
lst = [i ** 2 for i in range(5) if i % 2 == 1]
lst = [i ** 2 if i > 2 else i for i in range(5)]
```

## Модуль collections
### `defaultdict`
* Работает как обычный `dict`, но вместо выброса `KeyError` при отсутствии ключа создает этот ключ и заполняет его значением по умолчанию:
```python
from collections import defaultdict
dct = defaultdict(float)
dct[2]
```
* Вывод:
```text
0.0
```
```python
dct = defaultdict(list)
dct[2]
```
* Вывод:
```text
[]
```
```python
dct = defaultdict(lambda: len(dct))
dct[0], dct[1], dct[10]
```
* Вывод:
```text
(0, 1, 2)
```

### `deque`
* Используй `deque` для задач, требующих постоянного добавления или удаления элементов с краев (идеально для очередей "первый пришел — первый ушел").
* Обычный `list` лучше подходит для частого обращения к элементам по индексу.
```python
from collections import deque
deque([1,2,3])
q = deque([1,2,3])
q.appendleft(0)
q.append(4)
q.popleft()
q.pop()
```

### `OrderedDict`
* Порядок добавления ключей имеет значение при сравнении (в отличие от стандартного `dict`).
```python
from collections import OrderedDict
a = OrderedDict(); a[1] = 2; a[3] = 4
b = OrderedDict();  b[3] = 4; b[1] = 2
a == b
```
* Вывод:
```text
False
```
* Демонстрация методов перемещения и извлечения:
```python
d = OrderedDict([(1, 'a'), (3, 'c'), (2, 'b')])
print(d)
d.move_to_end(3, last=False)
print(d)
d.popitem(last=True)
print(d)
```
* Вывод:
```text
OrderedDict({1: 'a', 3: 'c', 2: 'b'})
OrderedDict({3: 'c', 1: 'a', 2: 'b'})
OrderedDict({3: 'c', 1: 'a'})
```

### `Counter`
* Специализированный словарь для быстрого подсчета элементов:
```python
from collections import Counter
Counter("aaabbbbccd")
```
* Вывод:
```text
Counter({'b': 4, 'a': 3, 'c': 2, 'd': 1})
```
* Счетчики поддерживают математические операции, например, вычитание:
```python
a = Counter("aaabbbbccd")
b = Counter("aaaab")
a - b
```
* Вывод:
```text
Counter({'b': 3, 'c': 2, 'd': 1})
```

#### heapq
* **Главная суть (Min-Heap):** Это структура данных, которая организует элементы массива так, чтобы самый маленький элемент всегда лежал на поверхности (под индексом `0`). Работает на списке. Инициализация:
```python
a = []
heapq.heappush(a, value)
b = [1, 2, 3, 4, 5]
heapify(b)
```
* **Применение:** Используйте `heapq` для быстрого поиска минимума, максимума или `k` самых больших/маленьких элементов без полной сортировки массива.

Добавление и удаление
* **`heappush(heap, item)`**
  Добавляет элемент `item` в кучу `heap`. Массив автоматически перестраивается, чтобы сохранить свойства кучи (минимум остается спереди).
* **`heappop(heap)`**
  Достает, удаляет и возвращает самый маленький элемент из кучи. В цикле элементы будут выходить строго по возрастанию (например: -1, 0, 1, 2, 4).
* **`heapreplace(heap, item)`**
  За один шаг удаляет самый маленький элемент из топа и ставит на его место новый `item`. Размер кучи при этом сохраняется неизменным.

Поиск экстремумов (Топ-K)
* **`nlargest(n, iterable)`**
  Возвращает список из `n` самых больших элементов в коллекции. Как показано в бенчмарках, это работает в десятки раз быстрее, чем полная сортировка массива с последующим срезом.
* **`nsmallest(n, iterable)`**
  Возвращает список из `n` самых маленьких элементов коллекции.
